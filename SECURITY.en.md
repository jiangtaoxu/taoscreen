# Reporting Security Issues

English · [简体中文](SECURITY.md)

If you find a security issue that affects remote access, device authorization, or credentials, report it through the repository's private vulnerability reporting feature. If private reporting is unavailable, use the contact details on the maintainer's GitHub profile to reach out privately.

Include the impact, affected TaoScreen and macOS versions, and the conditions needed to reproduce the issue. Replace real accounts, passwords, tokens, and device authorization data with test data before submitting.

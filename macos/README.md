# TaoScreen macOS

[返回项目首页](../README.md) · [完整使用指南](../docs/user-guide.md) · [服务端说明](../server/README.md)

<img src="Resources/Brand/TaoScreen-logo.png" alt="TaoScreen 双屏互联 Logo" width="128">

TaoScreen（涛子远程桌面）是用于 Mac 之间远程连接的桌面客户端。

最低 macOS 14，Swift 5 语言模式。依赖固定为 `stasel/WebRTC 154.0.0` 和 `Sparkle 2.10.0`。打包脚本随应用附带 WebRTC 和 Sparkle 的许可证。

应用图标采用深靛蓝圆角底、重叠的双屏轮廓和薄荷色指针，表现用一台 Mac 操控另一台 Mac。源图及生成说明见 [Resources/Brand](Resources/Brand/README.md)。`Resources/AppIcon.icns` 包含 16–1024 像素的标准及 Retina 图标，随应用一起打包。修改源图后可运行 `bash scripts/generate-app-icon.sh` 重新生成图标包。

## 构建与发布命令

| 任务 | 命令 | 产物与效果 |
| --- | --- | --- |
| 本地构建 | `./scripts/build-app.sh` | `dist/TaoScreen.app`，仅本机调试 |
| 正式打包 | `./scripts/build-release.sh` | 自动递增版本，测试、Developer ID 签名和 Apple 公证，生成 `dist/releases`；不上传 |
| 发布新版本 | `./scripts/publish-production.sh` | 同上并上传项目的独立 R2 桶，验证公开下载后更新清单，客户端和下载页发现新版本 |
| 上传已有版本 | `./scripts/upload-release.sh` | 上传 `dist/releases/macos-<架构>.json` 对应的已构建安装包，不重新打包 |
| 运行测试 | `swift test` | 客户端自动测试 |

打包和发布读取 `RELEASE_NOTES.md`，可以传入显式版本。发布所需的签名、更新源和上传目标由部署者配置，见下方「应用更新」。

## 构建与运行

需要 Xcode、Swift 和 XcodeGen（`brew install xcodegen`）。

```sh
swift test
scripts/build-app.sh
open "dist/TaoScreen.app"
```

脚本默认 Debug，可传 `Release`，生成 Xcode 工程、嵌入 WebRTC 并执行本机 ad-hoc 签名；设置 `TAOSCREEN_SIGN_IDENTITY` 时改用该证书签名并开启 Hardened Runtime。产物只验证本机架构；常规构建脚本不公证，也不会自动发布。也可打开 `TaoScreen.xcodeproj` 调试。`swift run` 适用于代码调试，实际屏幕权限与日常运行使用 app 产物。

本地服务地址 `http://127.0.0.1:28080`。远端连接仅接受 HTTPS 服务根地址。新应用需要自己的屏幕录制和辅助功能授权。

从源码构建后，在登录页输入自建服务地址。构建时可通过 `TAOSCREEN_DEFAULT_SERVER_URL` 预填地址。源码版使用 `org.taoscreen.development`，应用偏好、支持目录和钥匙串按 Bundle ID 与官方版隔离。fork 可以设置自己的 `TAOSCREEN_BUNDLE_ID`。自定义 OAuth 回调时，客户端的 `TAOSCREEN_OAUTH_CALLBACK_SCHEME` 与服务端的 `DESKTOP_OAUTH_CALLBACK_SCHEME` 填写相同的值，默认均为 `taoscreen`。

## 目录

- `Sources/TaoScreen/Desktop`：桌面引擎、捕获、控制、文件和隐私屏。
- `Sources/TaoScreen/Account`：独立登录状态、API、钥匙串和协议类型，不包含笔记同步。
- `Sources/TaoScreen/Files`：桌面文件通道必要工具。
- `Sources/TaoScreen/Support`：独立数据目录和防休眠。
- `Tests`：桌面回归及账号隔离测试；真实 API 测试通过 `TAOSCREEN_LIVE_TEST_URL` 显式开启。
- `Resources`、`project.yml`、`scripts`：应用元数据、XcodeGen 工程定义和打包。

普通文件接收到 `下载/TaoScreen`；按位置拖放先写入独立应用管理目录。关闭主窗口后保留菜单栏服务，可在菜单栏停止共享或退出。启动后远程桌面开关默认关闭。

## 账号登录

选择「账号连接」并填写服务地址。客户端显示服务器启用的登录方式。自托管实例启用本地账号后，使用管理员开通的邮箱和密码登录。Google / GitHub 通过浏览器完成授权，可以在账号菜单主动绑定。本地开发可填写 `http://127.0.0.1:28080`。自托管配置见[服务端登录说明](../server/docs/authentication.md#自托管登录)。

## 免登录直连

两台 Mac 都打开 TaoScreen，在主窗口顶部选择「免登录直连」，即可在不部署服务端、不登录账号的情况下互连。

被控端开启「允许临时连接」后会生成 6 位临时连接密码（默认监听 TCP `45871`），同时在「兼容连接码」菜单提供 `taoscreen-direct://` 连接链接与 `TS1-` 完整连接码。被控端「本机连接地址」卡片会自动探测并展示本机的 `Tailscale IP`、`MagicDNS` 与 `局域网 IP`（支持官网/Homebrew 版 Tailscale CLI 以及无 CLI 的 Mac App Store 版 `utun` 隧道接口回落检测），支持一键刷新与复制；控制端如运行 Tailscale CLI，还会在「Tailscale 在线 Mac」列表中看到当前在线的 macOS 节点。

- **同一局域网**：启用本地网络权限后，Bonjour 会自动发现「局域网附近设备」，点击「连接…」并输入 6 位临时密码或连接码即可发起请求。
- **通过 Tailscale / 指定地址**：在两台 Mac 上连通各自的 Tailscale 客户端后，控制端在「快速连接」填入被控 Mac 的 `Tailscale IP`、`MagicDNS` 名称或局域网 IP（或点击「Tailscale 在线 Mac」旁的「填入地址」），输入 6 位临时密码后点击「连接」。连接同时需要两端的防火墙与网络策略放行信令端口及 WebRTC 媒体流量。

临时密码与连接码握手采用**通道绑定 PAKE（Curve25519 Elligator2）**双向验证密码并绑定当前 TLS 证书指纹（连续错误 5 次锁定 60 秒），再由被控端逐次弹窗确认共享屏幕（主屏幕、物理显示器或虚拟屏）、是否允许键鼠控制和是否共享系统声音。接收端仅接受局域网私有网段、回环地址或 Tailnet 来源连接。该模式无需 TaoScreen Server、账号、STUN 或 TURN；保存远程登录密码一键解锁、断连锁屏和独立端口映射需使用账号模式。

### Tailscale 无人值守

Tailscale 无人值守仅接受来自 Tailscale 内网的连接请求，支持以下两种免人工确认方式（被控 Mac 的 macOS 用户需已登录；锁屏与熄屏后均可继续连接，可在设置弹窗开启「登录 macOS 后启动 TaoScreen」）：

1. **固定密码免确认（TCP `45873`）**：
   - 在被控 Mac 的「Tailscale 无人值守 → 管理固定密码与权限…」设置至少 8 个字符的固定访问密码（支持随机生成强密码），本地钥匙串仅保存加盐 PBKDF2-HMAC-SHA256 校验摘要（100,000 轮），不保存明文。
   - 配置默认共享屏幕（主屏幕或虚拟屏）、键鼠控制和系统声音权限并开启「固定密码免确认」，监听绑定到本机 Tailscale 地址与 TCP `45873`。
   - 控制端在「快速连接」填入目标 Tailscale IP 或 MagicDNS 与固定密码即可自动识别（8 位及以上）并经通道绑定 PAKE 验证后直接连入（连续错误 5 次锁定 60 秒）。
2. **可信设备配对免密（TCP `45872`）**：
   - 先用临时密码或连接码发起一次直连，被控 Mac 在确认共享时勾选「记为可信设备」，双方将各自的 P-256 设备公钥保存在本机钥匙串。
   - 在被控 Mac 打开「可信设备…」，开启「允许已配对设备通过 Tailscale 无人值守」，并按设备设置默认共享屏幕（主屏幕或虚拟屏）、键鼠或系统声音权限。监听绑定本机 Tailscale 地址与 TCP `45872`。
   - 控制端在「Tailscale 在线 Mac」点击「一键免密」，或在「已配对可信设备」点击「无人值守连接」即可免密连入。两端每次连接均用双向 TLS 验证设备公钥；关闭无人值守或撤销指定设备授权会立即中断对应共享。

> 无人值守直连支持屏幕共享及已授权的键鼠与系统声音；文件传输与自动剪贴板同步适用于逐次确认的直连或账号连接。系统休眠、退出用户会话或重启后，需等到用户会话和网络恢复可用。

## 远程连接权限

主窗口以同账号设备列表为主，顶部集中放置“访问权限”“无人值守”和“隐私屏”入口。隐私屏的自动启用、本次共享开关、样式选择、图片导入及预览在独立弹窗中设置，关闭弹窗不会停止已启用的隐私屏。

主界面的“权限检查…”、无人值守设置和来访确认窗口都可检查本机授权。被控电脑必须具备屏幕录制权限；允许控制时还需辅助功能和输入事件权限，仅观看不要求控制权限。返回应用时会刷新系统状态，也可点击“重新检查”。“打开录屏设置”和“打开辅助功能设置”分别进入对应系统页面。

“申请权限”只发起系统授权流程，不会把已申请视为已生效。缺少权限时，被控端显示提醒，发起端收到具体缺失项和重新连接步骤；采集服务明确拒绝授权时，必须重新验证，旧检查结果不能覆盖新的拒绝状态。权限完成后不会自动接受过期请求。

系统列表已勾选但应用检查仍未生效时，先确认列表对应当前安装的 TaoScreen，再使用“重启 TaoScreen…”；该操作会先确认并说明会结束连接、待确认请求及未保存设置，正常退出后重新打开同一个应用。未取得授权时不共享屏幕，不自动修改系统权限或重置系统授权记录。

## 虚拟屏

在被控 Mac 的连接确认窗口打开「共享屏幕」，可选 1920 × 1080、2560 × 1440 或 3840 × 2160 的虚拟屏。同账号无人值守在「无人值守」中保存选择，Tailscale 无人值守在「可信设备」中按设备设置。

被控端为每次连接创建一块 60 Hz 的 macOS 扩展显示器。4K 虚拟屏使用 HiDPI，对应 1920 × 1080 的逻辑工作区和 3840 × 2160 的显示像素。可在系统「显示器」设置中查看，并把要共享的窗口移到这块屏幕。画面仍使用远程窗口的画质设置，鼠标坐标对应虚拟屏的位置，键盘和系统声音沿用当前 macOS 用户会话。会话结束或退出 TaoScreen 后，系统移除虚拟屏。

虚拟显示器的创建依赖 macOS 非公开接口。锁屏和无实体显示器场景的表现取决于被控 Mac 的系统版本和显示环境。若系统无法创建或采集该虚拟屏，或会话期间虚拟屏被移除、变成镜像，本次共享会结束并显示原因。

## 本机保存远程密码与断连锁屏

在「登录密码与断连锁屏」中为被控 Mac 保存、重填或删除登录密码。密码按当前服务账号和被控设备分开保护在控制端本机钥匙串，关闭 iCloud 同步。设置页显示保存状态，升级前保存过的密码需要重新保存一次。

被控 Mac 已登录并锁屏时，在远程画面选中用户并点击密码框，再点击「验证后解锁」。用控制端的触控 ID 或本机登录密码完成系统验证。TaoScreen 再确认连接、设备、锁屏和键鼠授权，通过当前加密控制通道提交保存的密码，并等待被控端确认。取消、验证失败或连接变化会结束本次操作。关机、退出登录会话和 FileVault 启动阶段请按系统流程登录。

带 Secure Enclave 的 Mac 使用硬件私钥保护远程密码。有适当权限的其他 Mac 使用数据保护钥匙串。若构建需要启用数据保护钥匙串，请在打包时同时提供 `TAOSCREEN_SIGN_IDENTITY`、`TAOSCREEN_APP_ENTITLEMENTS`、`TAOSCREEN_PROVISIONING_PROFILE`，并为 Bundle ID 配置相应钥匙串权限。保存功能不可用时，可在远程画面手动输入密码。

“断开连接后锁定被控电脑”默认关闭。被控端确认后，选择按设备保存在控制端本机，下次连接可重新协商；被控端仅为当前已授权会话保留策略，不保存收到的密码。手动断开、控制端退出或网络异常且恢复失败导致会话结束时，由被控端执行系统标准 [⌃⌘Q 锁屏快捷键](https://support.apple.com/en-us/102650)。短暂重连和仅关闭远程窗口不结束会话，不立即锁屏；未建立连接、未授予控制或已经锁屏时不重复执行。需已有辅助功能和输入事件权限，系统未确认锁定时在被控端显示明确提示。

## 应用更新

配置了发布源的构建通过 Sparkle 2.10 在启动时和运行期间每分钟检查更新。有新版本时，主窗口右上角显示蓝色下载图标。点击图标可查看版本说明，再由 Sparkle 下载、验证、替换当前应用并重启。菜单中的“检查更新…”和设置中的“应用更新”使用同一流程。下载期间可继续使用，安装重启会结束当前远程连接。

Sparkle 使用 HTTPS appcast 和 Ed25519 公钥验证更新包。源码构建默认关闭更新检查。可以在构建时设置 `TAOSCREEN_UPDATE_FEED_URL` 和 `TAOSCREEN_UPDATE_PUBLIC_KEY` 接入自己的发布源。发布包使用 Developer ID 签名并通过 Apple 公证。

| 配置 | 用途 |
| --- | --- |
| `TAOSCREEN_SIGN_IDENTITY`、`TAOSCREEN_TEAM_ID`、`TAOSCREEN_NOTARY_PROFILE`、`TAOSCREEN_BUNDLE_ID` | 签名、公证及校验发布身份 |
| `TAOSCREEN_UPDATE_KEY_ACCOUNT` | 发布者的 Sparkle 钥匙串账户 |
| `TAOSCREEN_RELEASE_ORIGIN` | HTTPS 安装包和 appcast 源地址 |
| `TAOSCREEN_UPDATE_SERVER` | 可选的默认账号服务器地址，自动上传时用于确认下载 API |
| `TAOSCREEN_R2_ACCOUNT_ID`、`TAOSCREEN_R2_BUCKET` | 仅自动上传时配置的 R2 账户和存储桶 |

运行 `swift package resolve` 后，使用 `python3 scripts/package-release.py --init-update-key` 初始化更新密钥。私钥由 Sparkle 留在本机钥匙串，公钥默认保存到本地 `.release/update-public.plist`，也可通过 `TAOSCREEN_UPDATE_PUBLIC_KEY_FILE` 指向已有公钥文件。

运行 `scripts/build-release.sh` 生成 ZIP、DMG 和对应架构的 appcast、下载清单。手动部署时先上传安装包，检查下载内容，再发布清单。使用 R2 自动上传时，通过 `scripts/publish-production.sh` 构建并上传，也可以用 `scripts/upload-release.sh` 上传已有产物。自动上传会检查线上版本和签名。

### GitHub Release 安装包

先推送包含工作流的分支，再单独推送 `vX.Y.Z` 格式的 Git tag。[GitHub Actions](../.github/workflows/macos-release.yml) 会构建兼容 Apple Silicon 和 Intel 的 `TaoScreen-X.Y.Z-universal.dmg`，完成 Developer ID 签名、Apple 公证和 Gatekeeper 验证后上传到同一 tag 的 GitHub Release。也可在 Actions 页从 `main` 手动运行「发布 macOS DMG」，指定已经推送的 tag。仅验证公证流程时关闭上传选项，可从该次工作流下载产物。

GitHub 的 `macos-release` 环境允许 `main` 和版本标签。设环境变量 `MACOS_TEAM_ID`，并添加环境 Secrets `MACOS_SIGNING_P12`（Developer ID Application 的 `.p12` 文件经 Base64 编码）、`MACOS_SIGNING_P12_PASSWORD`、`MACOS_NOTARY_APPLE_ID` 和 `MACOS_NOTARY_PASSWORD`（Apple App 专用密码）。发布产物适用于免登录直连或自行配置服务器的使用场景。

在本机可运行 `python3 scripts/package-release.py --github-dmg v1.0.20` 从当前检出的源码生成临时签名 DMG，产物位于 `dist/`。已配置本机公证凭据时，可用 `--github-sign-dmg v1.0.20 dist/TaoScreen.app` 签名和公证该应用。

## 远程 Mac 操作

1.0.10 修复接收端覆盖系统生成的功能键/方向键标志的问题，并为顶部组合键发送完整的修饰键按下和释放事件。普通字母键的全屏组合在 1.0.9 可用，不代表功能键类系统快捷键也正常；被控端必须升级到修复版本。

控制端远程窗口顶部提供“所有窗口”（⌃↑）、“显示 Dock”（⌃F3），以及菜单中的当前应用窗口（⌃↓）、显示桌面（F11）、切换全屏（⌃⌘F）和 Esc。这些按钮直接向被控电脑发送标准快捷键，不受“快捷键接收端”本机/远端选择影响，不修改系统配置；若被控 Mac 自定义或关闭了对应快捷键，需要在该 Mac 恢复标准设置。仅在当前活动连接允许控制、开启鼠标键盘且未锁屏时可用。

## 远程画面设置

在远程窗口右上角打开“连接设置”，在“画面与声音”中通过“画质选择”切换五档画面模式，无需重新连接。在标题栏可切换“远端输入法”和“本机输入法”。使用这台 Mac 的输入法打字或语音输入时，选择带麦克风图标的“本机输入法”。

悬停在窗口标签的信号图标上可查看连接信息。点击图标或移入浮窗后固定，可通过关闭按钮或再次点击图标关闭。浮窗显示控制端和被控端当前连接的 IPv4/IPv6 地址，每两秒随实际选中链路刷新，断线后清除。中继候选标明“中继”，对应中继节点地址；未提供 IP、仅提供隐藏主机名或无法唯一确定选中链路时显示“未获取”，不读取其他网卡或外部 IP 查询服务作为替代。地址字段可选择复制。

可在连接期间切换的画面模式如下：

| 模式 | 16:9 分辨率上限 | 帧率上限 | 视频码率上限 |
| --- | --- | --- | --- |
| 节省流量 | 1280×720 | 15 帧/秒 | 4 Mbps |
| 标准 | 1920×1080 | 30 帧/秒 | 8 Mbps |
| 流畅优先 | 1920×1080 | 60 帧/秒 | 16 Mbps |
| 高清 | 2560×1440 | 30 帧/秒 | 16 Mbps |
| 超清（默认） | 3840×2160 | 30 帧/秒 | 24 Mbps |

默认保留原有的超清 30 帧。采集按屏幕实际像素和比例缩小，不放大低分辨率屏幕。设置内显示被控端确认的采集尺寸与帧率上限，不代表实时接收帧率；实际效果取决于设备性能和网络。网络受限时，流畅优先模式优先保持帧率，其余模式优先保持分辨率。

成功确认后，选择仅保存在控制端本机，按服务器、账号和被控设备隔离；重连自动应用。未确认或失败的选择不覆盖已保存偏好。切换超时显示状态未确认，可重试；切换失败会明确报告原配置恢复结果，无法确认恢复时停止共享。采集重建、锁屏恢复和隐私屏变化沿用当前已确认模式。两端均需支持本功能，旧版被控端未声明支持时禁用画面选择并提示升级。

## 双向 TCP / UDP 端口映射

参考 UU 远程的设备入口、映射列表和四字段编辑弹窗。点击设备卡片上的“端口映射”即可打开该设备的规则；主窗口顶部和菜单栏也能打开管理窗口、切换设备。打开时启用此电脑的端口服务并尝试连接所选在线设备，无需先建立远程桌面。

两台 Mac 需登录同一账号，对方需开启端口服务。接收端逐次允许或拒绝连接，也可以在“端口服务设置”中为当前账号开启自动允许。此授权独立于桌面无人值守权限；默认不自动允许，不申请屏幕录制或辅助功能权限。

添加规则只需填写名称、本地端口、目标地址和目标端口，默认 TCP、本机 `127.0.0.1` 监听。目标地址可以是所选 Mac 的 `127.0.0.1`、IPv4 / IPv6 / ASCII 主机名，也可以是它能访问的局域网设备。协议、反向映射及共享给局域网的监听范围收在“高级设置”中。

- 表格显示名称、本地或监听端口、目标地址、目标端口、映射状态和操作；每条规则可以独立启停，失败时保留具体原因，并支持重试。
- “保存后立即启用”默认勾选。未连接时只保存启用意图，连接及对方授权就绪后才创建监听。端口占用不会自动换端口或不断重试；“监听中”仅表示监听已建立，不代表目标服务可达。
- 支持编辑、删除及创建副本。运行中的规则先停用，收到停止确认后才能编辑或删除；创建副本随时可用，副本保留目标配置并清空本地端口，补充端口后才可保存。删除前确认。
- 已知设备、规则和启用状态按服务器账号及设备 ID 保存在本机。设备离线时仍可管理已保存规则，重新连接后恢复已启用规则。旧版规则默认迁移为停用，不自动开放已有监听。损坏记录会报错并保留，拒绝覆盖。
- **本机监听 → 远端目标**：例如此电脑的 `127.0.0.1:2222` 映射到所选 Mac 的 `127.0.0.1:22`。
- **远端监听 → 本机目标**：在高级设置中选择反向映射，例如所选 Mac 的 `127.0.0.1:15353` 映射到此电脑的 UDP DNS 服务。

关闭映射窗口前，如果本机仍有发起的映射连接，会确认是否断开；确认后停止这些连接及监听，保留规则和启用状态，下次连接后恢复。接收端端口服务和远程桌面不受此关闭操作影响。断开桌面不会停止映射；关闭端口服务、退出账号、退出应用、休眠或切换用户会停止连接和监听。

转发仍使用独立 WebRTC 加密连接及有界可靠数据通道，仅协商数据，不建立视频、声音或桌面控制通道。每次启停都通过独立运行 ID 确认，旧回执不会修改新一轮监听。短暂信令断线最多保留原通道 60 秒，仅在服务端验证原会话、双方登录与恢复随机码后恢复授权；授权失效即停止转发。实际数据通道恢复后，已启用规则会在收到上一轮停止确认后再启动。

服务端继续使用独立的 `/v1/ports/config`、`/v1/ports/peers`、`/v1/ports/signal` 及现有 TURN，不新增公网监听端口。协议保持兼容，不读取或接入 UU 的账号、凭据或连接服务。
